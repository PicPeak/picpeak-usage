# Weekly report previews

These screenshots show synthetic data from the weekly email Playwright fixtures,
not production messages. They are rendered by `test/browser/security.spec.ts`
(the `weekly email preview` cases) and are excluded from the downloadable source
archive and runtime web assets.

- [English, desktop](weekly-report-en-desktop.png)
- [German, mobile](weekly-report-de-mobile.png)

The English sample submission remains English when the surrounding email is
German: submitted messages are preserved verbatim.
